Wallet

Your CURS3D wallet, in your browser. Votre wallet CURS3D, dans votre navigateur.

Keys are generated locally, encrypted with your password (Argon2id + AES-256-GCM) and stored only in your browser. The private key never leaves the device. Signing happens on-device against the post-quantum ML-DSA-87 keypair. Les clés sont générées localement, chiffrées avec votre mot de passe (Argon2id + AES-256-GCM) et stockées uniquement dans le navigateur. La clé privée ne quitte jamais l'appareil. La signature s'effectue sur place avec la paire de clés post-quantique ML-DSA-87.

Create new wallet Créer un nouveau wallet

Generate a fresh ML-DSA-87 keypair locally. Choose a strong password — it encrypts your private key on this device. Générez une nouvelle paire de clés ML-DSA-87 localement. Choisissez un mot de passe robuste — il chiffre votre clé privée sur cet appareil.

Save the backup file.Sauvegardez le fichier de backup. We cannot recover your wallet from your password alone. If you lose both, your funds are gone forever. Nous ne pouvons pas récupérer votre wallet à partir du mot de passe seul. Si vous perdez les deux, vos fonds sont perdus pour toujours.

Import existing Importer un wallet

Paste your encrypted wallet JSON or upload the backup file. Enter the password used to encrypt it. Collez votre JSON de wallet chiffré ou téléversez le backup. Entrez le mot de passe utilisé pour le chiffrer.
