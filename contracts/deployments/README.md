# Deployments

Suggested filenames:
- `sepolia.json`
- `base-sepolia.json`

```json

  "network": "base-sepolia",
  "chainId": 84532,
  "deployer": "0x...",
  "token": "0x...",
  "faucet": "0x...",
  "staking": "0x...",
  "governance": "0x...",
  "attestations": "0x...",
  "vault": "0x...",
  "escrow": "0x..."
}
```
