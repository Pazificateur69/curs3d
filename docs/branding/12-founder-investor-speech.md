# Founder And Investor Speech

Mise a jour: 2026-05-04

Ce document sert de reference pour parler de `CURS3D` sans surpromettre. Il doit guider:
- le pitch fondateur
- les appels avec angel investors
- les intros partenaires
- le deck
- le site public
- les messages LinkedIn / X / Discord

## Qualification honnete du projet

Formulation recommandee:

`CURS3D is an advanced Rust-based post-quantum Layer 1 prototype with an experimental public testnet, EVM compatibility work, explorer, wallet path, SDKs, and a clear thesis around long-duration digital assets.`

Version francaise:

`CURS3D est un prototype avance de Layer 1 post-quantique en Rust, avec un testnet public experimental, un explorer, une trajectoire wallet, des SDKs, un travail de compatibilite EVM et une these claire autour des actifs numeriques de longue duree.`

Qualification courte:

`Advanced post-quantum L1 prototype.`

Qualification publique prudente:

`Experimental post-quantum Layer 1 testnet.`

Qualification investisseur:

`Early-stage post-quantum L1 infrastructure project, currently between technical prototype and credible public testnet.`

## Ce qu'il faut dire

`CURS3D` doit etre presente comme:
- une Layer 1 post-quantique native
- un projet infrastructure, pas un simple token
- un protocole experimental mais deja substantiel
- une these de categorie: securiser les actifs numeriques qui doivent durer
- une opportunite early, pas une promesse de domination

Phrase centrale:

`The core idea is simple: if digital assets are meant to last for years or decades, their cryptographic assumptions should be designed for that horizon.`

Version francaise:

`L'idee centrale est simple: si des actifs numeriques sont censes durer des annees ou des decennies, leurs hypotheses cryptographiques doivent etre pensees pour cet horizon.`

## Ce qu'il ne faut pas dire

Ne pas dire:
- `mainnet ready`
- `production ready`
- `quantum-proof`
- `unhackable`
- `next Ethereum`
- `guaranteed to win`
- `fully audited`
- `institutional ready`
- `ready for real user funds`

Ne pas vendre `CURS3D` comme une blockchain deja mature. La bonne posture est:

`serieux, early, ambitieux, lucide.`

## Demande investisseur recommandee

Positionnement de levee:

`technical angel / pre-seed exploration`

Ne pas positionner comme:

`growth round`, `token launch round`, `mainnet expansion round`.

Ticket coherent au stade actuel:
- discussion angel: oui
- petit ticket de conviction: possible
- grosse levee institutionnelle: prematuree sans testnet stable, audits, traction developpeur et clarification juridique

Utilisation des fonds a annoncer:
- stabilisation testnet
- finality, infra, monitoring
- audit externe
- wallet interop
- SDKs et devtools
- documentation developpeur
- premiers cas d'usage pilotes
- structuration juridique token / fondation

## Objections et reponses

### "Pourquoi une nouvelle L1 ?"

Reponse:

`Because the category is not just general-purpose execution. CURS3D is focused on long-term cryptographic durability. The point is not to out-Ethereum Ethereum; the point is to build a specialized trust layer for assets that need a longer security horizon.`

Version francaise:

`Parce que la categorie visee n'est pas simplement l'execution generaliste. CURS3D se concentre sur la durabilite cryptographique long terme. Le but n'est pas de battre Ethereum sur son propre terrain, mais de construire une couche de confiance specialisee pour les actifs qui ont besoin d'un horizon de securite plus long.`

### "Le marche post-quantique est-il trop tot ?"

Reponse:

`It may be early commercially, but infrastructure categories are usually built before the market fully prices the risk. The opportunity is to become credible before the category becomes obvious.`

Version francaise:

`Commercialement, c'est peut-etre tot. Mais les categories infrastructure se construisent souvent avant que le marche price completement le risque. L'opportunite, c'est de devenir credible avant que la categorie devienne evidente.`

### "Qu'est-ce qui existe deja ?"

Reponse:

`The project already has a substantial Rust protocol codebase, an experimental public testnet, API/RPC surface, explorer, SDKs, website, documentation, EVM compatibility work, and a defined brand/category thesis. The next step is not ideation; it is hardening, audit, reliability, and ecosystem proof.`

Version francaise:

`Il existe deja une codebase protocolaire Rust substantielle, un testnet public experimental, une surface API/RPC, un explorer, des SDKs, un site, de la documentation, un travail de compatibilite EVM et une these de categorie claire. La prochaine etape n'est pas l'idee; c'est le durcissement, l'audit, la fiabilite et la preuve ecosysteme.`

### "Qu'est-ce qui manque ?"

Reponse:

`The honest answer is: production maturity. The network still needs stronger operational reliability, external security review, clearer wallet interoperability, consistent public claims, and credible usage. That is exactly what the angel round is meant to fund.`

Version francaise:

`La reponse honnete, c'est la maturite production. Le reseau a encore besoin de meilleure fiabilite operationnelle, d'une revue securite externe, d'une interop wallet plus claire, de claims publics coherents et d'usages credibles. C'est precisement ce que la phase angel doit financer.`
